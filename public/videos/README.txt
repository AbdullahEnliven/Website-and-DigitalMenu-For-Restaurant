Tips
- Chef video: portrait (3:4) works best, chef in the middle, dark or black background. A .webm with a transparent background is the best.
- Keep each file small (under 8 MB for the chef, under 3 MB for the cards) so the page loads fast.
- Videos play muted and loop automatically, no sound is needed.
- If a file is missing the slot simply stays empty and the site still works.
